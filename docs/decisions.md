# شیوا گالری — تصمیم‌ها و نیازمندی‌ها

فروشگاه اینترنتی لباس زنانه. ریپوی قبلی (github.com/alirezaalamshah/Shiva-Gallery) فقط برای برداشتن مفاهیم خوانده شد؛ کد جدید از صفر نوشته می‌شود.

## تصمیم‌های قطعی

| موضوع | تصمیم |
|---|---|
| ساختار فنی | بک‌اند Django + DRF، فرانت Next.js (رندر سمت سرور برای سئو) |
| زیرساخت | بدون Docker. Celery و Redis هم فعلاً نه (پیشنهادی) |
| استایل | حرفه‌ای، جذاب، به‌یادماندنی، با انیمیشن‌های قوی. رنگ برند مشکی و طلایی (`#C9A24C`) از روی لوگو |
| دستگاه | ۹۹٪ مشتری‌ها با موبایل می‌آیند ← طراحی اول برای موبایل، دسکتاپ هم کامل |
| فروشگاه حضوری | دزفول. مغازه و پیج اینستاگرام موجودی و همه‌چیز جدا از سایت دارند ← نیازی به هماهنگی موجودی نیست |
| پنل مدیریت | پنل راحت و کاربردی برای افزودن لباس، دسته‌بندی، قیمت و هر چیز لازم |
| ورود مشتری | فقط موقع پرداخت، با شماره موبایل و کد پیامکی. بدون رمز عبور |
| ارسال | پیک داخل شهر (دزفول)، پست پیشتاز، تیپاکس. (تحویل حضوری از مغازه انتخاب نشد) |
| هزینه‌ی ارسال | فقط مبلغ ثابت برای هر روش (قابل تنظیم در پنل). ارسال رایگان نداریم |
| تم | روشن (کرم/سفید) با مشکی و طلایی به‌عنوان رنگ برند |
| عکس محصولات | ترکیبی (هم تن مدل، هم زمینه‌ی ساده). سایت باید با هر دو خوب کار کند: قاب و نسبت یکسان، برش خودکار |
| پرداخت | فعلاً درگاه نداریم؛ بعداً گرفته می‌شود. بخش پرداخت جداگانه و قابل‌اتصال طراحی شود تا بعداً درگاه بدون تغییر بقیه‌ی سایت اضافه شود |
| امکانات نسخه‌ی اول | علاقه‌مندی‌ها و «موجود شد خبرم کن»، کد تخفیف (و قیمت حراجی)، نظر و امتیاز فقط از خریدار با تأیید ادمین، پیگیری سفارش با پیامک |
| پوشه‌ی پروژه | `D:\projects-new-erfan\ShivaGallery` (پروژه داخل همین پوشه ساخته می‌شود) |

## مفاهیمی که از ریپوی قبلی نگه می‌داریم

- محصول ← تنوع (رنگ × سایز) با SKU، موجودی و قیمت جدا
- نوع سایزبندی برای هر دسته: حروفی، عددی، فری‌سایز
- دفتر موجودی فقط‌افزودنی (فروش، مرجوعی، اصلاح دستی)
- سفارش با ذخیره‌ی آدرس، قیمت و مشخصات لحظه‌ی خرید و تاریخچه‌ی وضعیت
- سبد مهمان که بعد از ورود با سبد حساب ادغام می‌شود
- دسته‌ها: مانتو، پالتو، شلوار، دامن، بلوز، مجلسی، ست، راحتی، شال و روسری، اکسسوری، کیف و کفش

## نقاط ضعف ریپوی قبلی که باید درست شوند

- تسویه‌حساب ناقص (ارسال، هزینه، پرداخت، صفحه‌ی موفقیت)
- سئوی ضعیف (فقط رندر سمت مرورگر)
- «مقایسه‌ی محصول» بی‌کاربرد برای لباس ← حذف

## سؤال‌های باز

- تعداد تقریبی محصولات؛ آیا کیف و کفش هم هست؟
- تسویه‌حساب یک‌صفحه‌ای؟ [پیشنهاد: بله]
- جدول سایز و شرایط مرجوعی [پیشنهاد: جدول سایز کنار انتخاب سایز، مرجوعی ۷ روزه]
- سایت مرجع
- نقش‌های پنل مدیریت [پیشنهاد: مدیر، فروشنده، انباردار]
- هاست و دامنه
- پنل پیامک
