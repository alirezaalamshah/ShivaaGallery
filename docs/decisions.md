# شیوا گالری — تصمیم‌ها و نیازمندی‌ها

فروشگاه اینترنتی لباس زنانه. ریپوی قبلی (github.com/alirezaalamshah/Shiva-Gallery) فقط برای برداشتن مفاهیم خوانده شد؛ کد جدید از صفر نوشته می‌شود.

## تصمیم‌های قطعی

| موضوع | تصمیم |
|---|---|
| قابلیت توسعه | سایت قابل رشد و قابل واگذاری به فروشگاه‌های دیگر باشد، نه مخصوص شیوا گالری. اسم، لوگو، رنگ‌ها، دسته‌ها، سایزبندی، روش‌های ارسال و متن‌ها از پنل/تنظیمات بیایند، نه داخل کد. از تعداد کم تا زیاد محصول جواب بدهد (فیلتر، جستجو، زیردسته) |
| مدل چندفروشگاهی | فعلاً هر فروشگاه نصب جدا (سرور، دامنه و دیتابیس خودش). کد از ابتدا آماده‌ی تبدیل به پلتفرم چندفروشگاهی: تنظیمات فروشگاه در یک مدل مرکزی، بدون مقدار ثابت در کد، تا بعداً بدون بازنویسی کامل چندفروشگاهی شود |
| ساختار فنی | بک‌اند Django + DRF، فرانت Next.js (رندر سمت سرور برای سئو) |
| زیرساخت | بدون Docker. Celery و Redis هم فعلاً نه (پیشنهادی) |
| استایل | حرفه‌ای، جذاب، به‌یادماندنی، با انیمیشن‌های قوی. رنگ برند مشکی و طلایی (`#C9A24C`) از روی لوگو |
| دستگاه | ۹۹٪ مشتری‌ها با موبایل می‌آیند ← طراحی اول برای موبایل، دسکتاپ هم کامل |
| دسته‌های اصلی | از پیج اینستاگرام (instagram.com/shivagallery1335): مانتو مجلسی، مانتو اداری، عبا، شومیز و شلوار. دسته‌ها از پنل قابل تغییرند |
| فروشگاه حضوری | دزفول، خیابان شریعتی، بین پاساژ ولیعصر و بانک صادرات. تلفن: ۰۹۱۶۶۴۴۶۲۰۰. سفارش فعلاً از دایرکت اینستاگرام گرفته می‌شود. مغازه و پیج اینستاگرام موجودی و همه‌چیز جدا از سایت دارند ← نیازی به هماهنگی موجودی نیست |
| پنل مدیریت | پنل راحت و کاربردی برای افزودن لباس، دسته‌بندی، قیمت و هر چیز لازم. فقط یک نقش: مدیر با دسترسی کامل (بدون سیستم نقش‌ها در نسخه‌ی اول). داخل خود سایت در `/panel`، **طراحی اول برای کامپیوتر** (مدیر با کامپیوتر کار می‌کند؛ مشتری با موبایل). ورود مدیر با نام کاربری و رمز. پنل جنگو فقط ابزار پشتیبان است |
| ورود مشتری | فقط موقع پرداخت، با شماره موبایل و کد پیامکی. بدون رمز عبور |
| تسویه‌حساب | یک صفحه: موبایل و کد پیامکی، آدرس، روش ارسال، کد تخفیف، پرداخت؛ خلاصه‌ی سفارش ثابت پایین صفحه |
| سایز و مرجوعی | همه از پنل قابل تنظیم: جدول سایز هر دسته (کنار انتخاب سایز)، روشن/خاموش بودن مرجوعی، نوع آن (بازگشت پول یا فقط تعویض سایز)، مدت آن، و متن قوانین مرجوعی |
| ارسال | پیک داخل شهر (دزفول)، پست پیشتاز، تیپاکس. (تحویل حضوری از مغازه انتخاب نشد) |
| هزینه‌ی ارسال | فقط مبلغ ثابت برای هر روش (قابل تنظیم در پنل). ارسال رایگان نداریم |
| تم | روشن ولی گرم و بدون سفیدی خیره‌کننده: زمینه‌ی شنی/کتانی (`#EEE5D6`)، سطح‌های کرم (`#F7F1E7`) به‌جای سفید، مشکی و طلایی برای برند، و یک نوار قهوه‌ای تیره (`#2A211B`) برای محصول ویژه. خاص و جذاب، نه سفید و ساده |
| عکس محصولات | ترکیبی (هم تن مدل، هم زمینه‌ی ساده). سایت باید با هر دو خوب کار کند: قاب و نسبت یکسان، برش خودکار |
| عکس‌ها | هنگام آپلود در پنل، هر عکس در یک پنجره‌ی برش با قاب ۳:۴ سایت تنظیم می‌شود (کشیدن و بزرگ‌نمایی، یا برش خودکار همه). در مرورگر فشرده و بعد در سرور همیشه به WebP با اندازه‌ی ثابت ۱۲۰۰×۱۶۰۰ ذخیره می‌شود (لوگو ۶۰۰×۶۰۰). |
| قیمت تنوع‌ها | هر رنگ × سایز می‌تواند قیمت خودش را داشته باشد (جدول قیمت کنار جدول موجودی در پنل). قیمت حراج هم صریح برای هر رنگ × سایز در جدول جداگانه وارد می‌شود (حراج کلی محصول نداریم). در هر دو جدول یک قیمت را می‌شود یک‌جا روی همه، یا روی یک رنگ یا یک سایز اعمال کرد. خانه‌ی خالی در جدول قیمت یعنی قیمت خود محصول و در جدول حراج یعنی حراج نیست. کارت محصول ارزان‌ترین تنوع را نشان می‌دهد |
| آدرس | انتخاب استان و سپس شهرهای همان استان؛ «شهر دیگر» برای شهرهای خارج از فهرست |
| متن‌ها | متن‌های توضیحی اضافه که مشتری را سردرگم می‌کند حذف شد؛ «ورود با کد پیامکی» به جای «ورود با موبایل» |
| کپی‌رایت | تمامی حقوق وب‌سایت متعلق به شیوا گالری (نام فروشگاه از تنظیمات)؛ «طراحی و توسعه: هوشیوا» با لینک houshiva.ir در فوتر |
| پرداخت | فعلاً درگاه نداریم؛ بعداً گرفته می‌شود. بخش پرداخت جداگانه و قابل‌اتصال طراحی شود تا بعداً درگاه بدون تغییر بقیه‌ی سایت اضافه شود |
| امکانات نسخه‌ی اول | علاقه‌مندی‌ها و «موجود شد خبرم کن»، کد تخفیف (و قیمت حراجی)، نظر و امتیاز فقط از خریدار با تأیید ادمین، پیگیری سفارش با پیامک |
| پنل پیامک | ملی‌پیامک (هنوز گرفته نشده). بخش پیامک قابل‌اتصال ساخته شود؛ در زمان توسعه کدها در کنسول نمایش داده شوند |
| هاست و دامنه | هاست اشتراکی cPanel؛ کد از ریپوی خصوصی گیت‌هاب گرفته می‌شود. بک‌اند روی زیردامنه‌ی api با Setup Python App، سایت روی دامنه‌ی اصلی با Setup Node.js App. راهنما: `deploy/README.md` |
| پوشه‌ی پروژه | `D:\projects-new-erfan\ShivaGallery` (پروژه داخل همین پوشه ساخته می‌شود) |

## مفاهیمی که از ریپوی قبلی نگه می‌داریم

- محصول ← تنوع (رنگ × سایز) با SKU، موجودی و قیمت جدا
- نوع سایزبندی برای هر دسته: حروفی، عددی، فری‌سایز
- دفتر موجودی فقط‌افزودنی (فروش، مرجوعی، اصلاح دستی)
- سفارش با ذخیره‌ی آدرس، قیمت و مشخصات لحظه‌ی خرید و تاریخچه‌ی وضعیت
- سبد مهمان که بعد از ورود با سبد حساب ادغام می‌شود
- دسته‌ها: مانتو، پالتو، شلوار، دامن، بلوز، مجلسی، ست، راحتی، شال و روسری، اکسسوری، کیف و کفش

## نقاط ضعف ریپوی قبلی که باید درست شوند

- تسویه‌حساب ناقص (ارسال، هزینه، پرداخت، صفحه‌ی موفقیت)
- سئوی ضعیف (فقط رندر سمت مرورگر)
- «مقایسه‌ی محصول» بی‌کاربرد برای لباس ← حذف

## سؤال‌های باز

همه‌ی سؤال‌های اولیه جواب گرفتند. سایت مرجع ندارند؛ طراحی با الهام از بهترین فروشگاه‌های مد دنیا پیشنهاد و برای تأیید ارائه می‌شود.
