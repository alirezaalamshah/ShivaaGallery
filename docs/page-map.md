# نقشه‌ی صفحه‌ها و مسیر خرید

بر پایه‌ی [decisions.md](decisions.md). طراحی اول برای موبایل؛ هر چیزی که اسم یا مقدار فروشگاه دارد از تنظیمات پنل می‌آید.

## مسیر خرید (موبایل)

```
صفحه‌ی اصلی / دسته / جستجو
        ↓
صفحه‌ی محصول ── انتخاب رنگ و سایز ── (جدول سایز)
        ↓  «افزودن به سبد» → سبد کشویی از پایین باز می‌شود
سبد خرید (بدون ورود، سبد مهمان)
        ↓  «ادامه‌ی خرید»
تسویه‌حساب یک‌صفحه‌ای:
   ۱. شماره موبایل ← کد پیامکی (ورود همین‌جا؛ سبد مهمان ادغام می‌شود)
   ۲. آدرس (آدرس‌های قبلی برای مشتری برگشتی)
   ۳. روش ارسال: پیک داخل شهر / پست پیشتاز / تیپاکس (مبلغ ثابت هر روش)
   ۴. کد تخفیف
   ۵. پرداخت (فعلاً غیرفعال تا درگاه گرفته شود)
   [خلاصه‌ی سفارش و دکمه‌ی پرداخت ثابت پایین صفحه]
        ↓
صفحه‌ی موفقیت + پیامک ثبت سفارش ← پیگیری سفارش
```

اصول: هیچ‌جا ثبت‌نام جدا یا رمز عبور نیست. موجودی هر سایز قبل از افزودن به سبد دیده می‌شود. سایز ناموجود ← «موجود شد خبرم کن». مشتری هیچ‌وقت از صفحه‌ی محصول بیرون پرتاب نمی‌شود.

## صفحه‌های مشتری

| صفحه | محتوا |
|---|---|
| خانه | بنر/اسلایدر از پنل، دسته‌های اصلی، تازه‌ها، پرفروش‌ها، حراجی، بخش‌های قابل چیدمان از پنل |
| فهرست دسته | زیردسته‌ها، فیلتر (سایز، رنگ، بازه‌ی قیمت، موجود)، مرتب‌سازی، بارگذاری پیوسته |
| جستجو | پیشنهاد هم‌زمان با تایپ، نتیجه با همان فیلترها |
| محصول | گالری عکس (کشیدنی، بزرگ‌نمایی)، رنگ‌ها، سایزها با وضعیت موجودی، جدول سایز، قیمت و حراجی، توضیحات، نظرات خریداران، محصولات مشابه |
| سبد خرید | تغییر تعداد/حذف، جمع، دکمه‌ی ادامه |
| تسویه‌حساب | طبق مسیر بالا |
| موفقیت سفارش | شماره‌ی سفارش، خلاصه، لینک پیگیری |
| حساب من | سفارش‌ها و وضعیت، آدرس‌ها، علاقه‌مندی‌ها، درخواست مرجوعی/تعویض، خروج |
| پیگیری سفارش | با شماره‌ی سفارش و موبایل، بدون ورود |
| صفحه‌های متنی | درباره‌ی ما، تماس (آدرس مغازه، نقشه)، قوانین مرجوعی، سؤالات متداول — همه از پنل |

ناوبری موبایل: نوار پایین ثابت (خانه، دسته‌ها، جستجو، سبد، حساب).

## پنل مدیریت (یک مدیر، فارسی، موبایل‌پسند)

| بخش | کارها |
|---|---|
| داشبورد | فروش امروز/هفته، سفارش‌های جدید، کالاهای رو به اتمام |
| محصولات | افزودن سریع با عکس‌ها، ساخت خودکار تنوع‌ها از رنگ × سایز، قیمت و حراجی، موجودی هر تنوع، کپی محصول |
| دسته‌ها | درخت دسته و زیردسته، نوع سایزبندی، جدول سایز هر دسته |
| ویژگی‌ها | رنگ‌ها (با نمونه‌ی رنگ)، سایزها |
| سفارش‌ها | فهرست با فیلتر وضعیت، تغییر وضعیت (پیامک خودکار)، ثبت کد رهگیری، چاپ برچسب ارسال |
| مرجوعی‌ها | درخواست‌ها، تأیید/رد، برگشت به موجودی |
| مشتری‌ها | فهرست، سفارش‌های هر مشتری |
| تخفیف‌ها | کدهای درصدی/مبلغی، تاریخ انقضا، سقف استفاده |
| نظرات | تأیید/رد |
| ظاهر سایت | لوگو، رنگ‌ها، بنرها، چیدمان صفحه‌ی اصلی، صفحه‌های متنی |
| تنظیمات | اسم و اطلاعات فروشگاه، روش‌های ارسال و هزینه، قوانین مرجوعی، پیامک (ملی‌پیامک)، درگاه پرداخت |

## ساختار فنی

```
ShivaGallery/
├── backend/    Django + DRF  — API، پنل، منطق سفارش و موجودی
├── frontend/   Next.js       — سایت مشتری و پنل مدیریت، رندر سمت سرور
└── docs/
```

- اتصال‌های بیرونی (پیامک، درگاه پرداخت) پشت یک رابط قابل تعویض؛ در توسعه، پیامک در کنسول چاپ می‌شود.
- تنظیمات فروشگاه در یک مدل مرکزی؛ هیچ مقدار ثابت شیوا گالری در کد نیست (آماده‌ی چندفروشگاهی در آینده).
- دیتابیس: SQLite برای توسعه، PostgreSQL برای سرور.
